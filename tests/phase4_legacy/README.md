# Legacy Phase 4 qualification tests

These tests exercise the superseded T00–T24 preparation design. They are retained
for historical diagnosis, but are not part of the D00–D15 Phase 4 real-model MVP
acceptance suite. Several require an immutable preparation release that is absent
from this repository; no replacement identity may be fabricated.

The canonical Phase 4 command discovers only `tests/phase4/test_*.py`.
