# Phase4E32 DLT 模型选择交付说明

## 候选空间

本轮使用 1,430 期 DLT 数据，穷举 48 个合法配置：A（逐号码逻辑回归）的
3 个逐号码子集、B（逐号码加 7 项逐期上下文）的 4 个子集、C（12 个逐号码
特征生成候选，11 项组合结构/行为特征重排）的 1 个固定子集，分别乘以
λ ∈ {1e-4, 1e-3, 1e-2} 与 W ∈ {30, 60}。代码中的 Markov 特征展开为两个
数值列，因此“12/19”沿用特征族口径，实际设计矩阵会多一个数值列。

B 的上下文包括 weekday、days_since_draw、rule_regime、ball_set_id、销售额
log1p、奖池 log1p、出球顺序可用性。由于源文件不能证明目标期销售额在截止
前已封存，销售额和奖池均使用上一期已公布值；缺失的球组和顺序显式编码为 0。

## 评估口径与无泄漏约束

最后 120 期逐期 walk-forward。预测 t 时，模型参数、历史特征和 z-score 统计
只包含 `[0,t)`；预测完成后才用 t 的标签更新。前区按概率取 Top-10，后区取
Top-4，记录每期命中数；均匀期望分别为 1.428571 和 0.666667，合计
2.095238。同时对全部逐号码二元标签记录 log loss。完整逐项结果见
`artifacts/phase4e32_model_search/candidates.jsonl`。

## 最优配置与结果

按预注册的 Top-K 合计命中均值降序、log loss 升序排序，最优配置为：

- family A，`statistical-only(9)`，λ=0.01，W=30；
- 合计 Top-K 命中均值 2.183333（均匀期望 2.095238，差 0.088095）；
- 前区 Top-10 命中均值 1.541667，后区 Top-4 命中均值 0.641667；
- 平均二元 log loss 0.430341137（均匀基线 0.430338764，模型差
  +0.000002374，即略差）。

## 科学结论

`no_confirmed_lift`。

虽然在被搜索的同一 120 期窗口里，最优候选的 Top-K 命中均值高于均匀期望，
但其 log loss 略差，而且这是从 48 个候选中事后取最大值。best-of-N 会产生上偏，
这里没有独立确认窗，也未做支持“显著提升”的预注册检验。因此不声称 lift、收益
或中奖能力。**建议扩大特征输入**，并在新的、未参与模型选择的独立数据上确认。

## 局限

数据只覆盖 1,430 期，最终评估窗仅 120 期；部分环境字段缺失；逐期上下文对同一
期所有号码相同，主要影响概率校准而非号码内部排序；C 的候选生成限制在第一阶段
排名靠前的号码池，未穷举全部彩票组合；在线确定性拟合是固定优化方案而非对优化器
本身的搜索。所有候选共享同一个评估窗，候选间结果高度相关。
