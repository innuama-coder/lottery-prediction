# Phase4E31 DLT 基线模型与 walk-forward 评估

## 模型口径

模型把每期每个候选号码视为一个二元观测，分别拟合前区和后区的 L2 逻辑回归：
`p(n)=sigmoid(intercept + theta·z(f(n)))`。训练目标是训练前缀上所有号码“出现/未出现”的
二元对数似然。输出概率是逐号码边际条件概率；它们不强制每期总和恰好为 5 或 2，也不应解释为
彩票投注收益或中奖保证。

任务指定的 12 个特征族直接复用 e29 的 sequence-safe 函数。Markov 特征按预注册要求展开
`P(1|1)`、`P(1|0)` 两列，所以数值设计矩阵共 13 列；run-length 使用
`terminal_length`。无法转成有限数值的缺省值补 0，模型另含一个不正则化的截距。

## 预注册与防泄漏

- 数据固定为 1,430 期 DLT 全量数据，评估窗口固定为最后 120 期。
- 每个目标期 `t` 的特征只由 `[0,t)` 产生；标签和拟合数据也只来自 `[0,t)`。
- λ 候选固定为 `1e-4 / 1e-3 / 1e-2`。每个 t、每个区分别在训练前缀末段做时间验证，
  选定后在该训练前缀全量重拟合。λ 选择不读取 t 或未来期。
- z-score 的均值和标准差仅从当前拟合所用的训练前缀计算。实现无随机抽样，同一输入确定性一致。
- 逐期记录包含训练边界、λ 选择明细、参数和标准化统计量，以便审计点时语义。

## 样本外结果

机器可读的完整结果在 `artifacts/phase4e31_baseline/summary.json`，120 个逐期预测在
`walk-forward.jsonl`。报告模型与均匀边际基线（前区 `5/35`、后区 `2/12`）的平均二元
log loss、归一化平均位次及预注册 Top-K 命中率。显著性口径为每期前后区 log loss 之和的
配对双侧正态近似检验，alpha=0.05；只有均匀损失减模型损失为正且 p<0.05 才允许写确认提升。

本次产物的科学结论以 summary 的 `scientific_conclusion` 为准。若其值为
`no_confirmed_lift`，结论就是相对均匀基线没有确认的样本外提升，不能改写成“有信号”或
“有提升”。即使检验偶然通过，它也只表示该预注册统计口径下的检测结果，不表示经济收益。

## 局限

号码同一期内受固定抽取数量约束，二元观测并非相互独立；当前模型没有显式建模这种联合结构。
单一 120 期窗口、同一游戏和多个特征/λ 选择限制了外推性。正态近似对时间依赖和厚尾的处理
有限，未做多重检验校正。特征多为短窗口历史统计，且彩票机制理论上接近独立随机抽取；因此
任何弱差异都应保守解释，并需要新的、完全未触碰的数据重复验证。
