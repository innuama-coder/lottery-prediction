# Phase 4 固定奖金计算冻结说明

## 规则边界

本文档冻结双色球（SSQ）和超级大乐透（DLT）的常规奖金计算。奖金计算是回测指标和模型验收的硬约束；实现、测试和产物必须与本文件保持一致。

一等奖和二等奖固定为：

| 彩种 | 一等奖 | 二等奖 |
| --- | ---: | ---: |
| 双色球 | 5,000,000 元 | 100,000 元 |
| 大乐透 | 5,000,000 元 | 100,000 元 |

统一原则：每个彩种只有一套固定奖金政策。超级大乐透不存在“新规则/旧规则”两套计算逻辑；期号只用于校验数据格式和完整性，不用于切换奖金表。不考虑奖池余额、浮动奖金、非常规派奖、营销活动或其他期次特例。一、二等奖固定为 5,000,000 / 100,000 元。未列入表格的命中状态不中奖，奖金为 0 元。

## 双色球固定奖金

双色球一注为 6 个红球和 1 个蓝球，命中状态为 `(红球命中数, 蓝球命中数)`：

| 奖级 | 命中状态 | 固定奖金（元） |
| --- | --- | ---: |
| 一等奖 | `(6,1)` | 5,000,000 |
| 二等奖 | `(6,0)` | 100,000 |
| 三等奖 | `(5,1)` | 3,000 |
| 四等奖 | `(5,0)`, `(4,1)` | 200 |
| 五等奖 | `(4,0)`, `(3,1)` | 10 |
| 六等奖 | `(2,1)`, `(1,1)`, `(0,1)` | 5 |

## 超级大乐透固定奖金

超级大乐透一注为 5 个前区号码和 2 个后区号码，命中状态为 `(前区命中数, 后区命中数)`：

| 奖级 | 命中状态 | 固定奖金（元） |
| --- | --- | ---: |
| 一等奖 | `(5,2)` | 5,000,000 |
| 二等奖 | `(5,1)` | 100,000 |
| 三等奖 | `(5,0)`, `(4,2)` | 5,000 |
| 四等奖 | `(4,1)` | 300 |
| 五等奖 | `(4,0)`, `(3,2)` | 150 |
| 六等奖 | `(3,1)`, `(2,2)` | 15 |
| 七等奖 | `(3,0)`, `(2,1)`, `(1,2)`, `(0,2)` | 5 |

## 计算约束

- 计算输入是单注的前区命中数和后区命中数，不接受浮动奖金字段。
- 每个命中状态最多对应一个奖级；未中奖状态返回 `0`。
- 奖级映射、金额和规则版本均为唯一规则模块中的不可变源码常量，不从开奖页面文本或派奖字段动态推断。
- 期号必须是严格的 `YYYYNNN` 字符串（年份 2000–2099、期序号 001–999）；无法严格解析的期号不得自动选择奖级版本。
- 无效命中数、未知规则版本和促销规则标识必须失败闭合。
- 规则表和金额表是不可变源码常量，唯一事实源为 `src/lottery_system/phase4/bonus.py`；`prizes.py` 仅为兼容封装。
- 重算产物必须记录奖金契约指纹；没有匹配指纹的旧产物禁止通过 `--resume-existing` 复用。
- 测试和独立 oracle 只校验双色球一套规则与大乐透一套规则的全部命中状态及全空间组合计数、固定奖金总额。

分组奖金指标定义为：`分组奖金总额 = Σ 单注固定奖金`，`分组平均奖金 = 分组奖金总额 / 完整注数`，`中奖率 = 获得任一固定奖级的完整注数 / 完整注数`。任何预测回测或组奖金汇总都必须调用 `bonus.py` 的统一入口，不得复制局部奖级判断。

独立全空间 oracle 的冻结验收值为：双色球固定奖金总额 15,117,950 元、中奖注数 1,188,988；大乐透固定奖金总额 18,890,405 元、中奖注数 1,429,197。没有匹配奖金契约指纹的历史产物不得通过 `--resume-existing` 复用。
