# Phase 4 路径 B：parimutuel 奖金模型与热门号规避 —— 总体方案与详细计划

## 1. 背景与目标

在冻结固定奖金契约（`docs/phase4/prize-calculation-contract.md`）下，每注期望奖金恒为 SSQ 0.8531 / DLT 0.8817 元，任何选号/分组/覆盖手段都无法提升期望（路径 C 已证伪"分组内每注平均奖金 > 2 元"）。路径 B 是唯一能在期望上产生正增量的方向：**一等奖（两彩种）与二等奖（大乐透）在真实规则中是 parimutuel 奖池分摊**，选冷门号码虽不改变中奖概率，但中奖时与更少人分池、期望更高；奖池滚存（rollover）抬高一等奖期望，也提供择时空间。

B 不保证达到 2 元；它只是唯一有真实上行空间、且各子杠杆可累加的路径。

## 2. 关键数据事实（决定 B 的落地边界）

| 输入 | 官方是否公布 | 可得性 |
| --- | --- | --- |
| 全国销量总额 | 是 | DLT 广东体彩静态页可得；SSQ 暂无获准来源 |
| 奖池滚存 | 是 | 同上 |
| 各奖级中奖注数 | 是 | 同上 |
| **号码级投注热度** | **否** | 只能代理（历史开奖热度、生日号、第三方合规热度） |

因此 B 拆成两个层次：**B0（纯代码模型，本次交付）** 与 **B1/B2（真实数据采集 + 热度代理，需另行授权）**。

## 3. 总体方案

```mermaid
flowchart LR
  B0[B0 版本化 parimutuel 奖金 + EV 模型] --> B1[B1 DLT 外部数据采集 + available_at 治理]
  B1 --> B2[B2 号码热度代理]
  B2 --> B3[B3 真实历史 walk-forward 回测]
  B3 --> B4[B4 challenger/shadow 服务治理]
```

## 4. 详细计划

### B0：版本化 parimutuel 奖金 + EV 模型（本次交付）

- 新增模块 `src/lottery_system/phase4/parimutuel.py`，**不修改** `bonus.py` 的冻结固定奖级表与契约指纹。
- 新增规则版本 `SSQ_PRIZE_PARIMUTUEL_v1` / `DLT_PRIZE_PARIMUTUEL_v1`（与冻结固定规则并存，非"新/旧规则"切换）。
- `parimutuel_bonus(game, front_hits, back_hits, *, tier1_pool, tier1_winners, tier2_pool, tier2_winners)`：低奖级沿用冻结固定值；一等奖/二等奖按 `pool / winners` 分摊。
- `expected_ticket_value(...)`：`EV = 低奖级固定期望 + P(一等奖)×E[一等奖分摊] + P(二等奖)×E[二等奖分摊]`，其中一等奖分摊 `pool1 / (其他中奖者数 + 1)`，其他中奖者数 = `(总投注数 - 1) × P(一等奖) × 号码热度权重 w`。w=1 均匀、w<1 冷门、w>1 热门。
- 声明为**模型**：parimutuel 分摊公式为带假设的抽象，不声称与官方精确规则逐字一致；公式参数化，待 B1 真实数据接入。

### B1：DLT 外部数据采集（需授权，另行立项）

- 广东体彩静态页解析：全国销量、奖池、各奖级中奖注数、奖金。
- 逐期建立 `available_at_utc < prediction_locked_at` 证明、provenance、冻结请求预算；遵守 `external_point_in_time` 治理。
- SSQ 需另寻获准来源，否则 B 先只覆盖 DLT。

### B2：号码热度代理（需授权）

- 官方无号码级热度，只能做可审计代理：历史开奖热度、生日号(1–31)、连号/尾号、第三方合规热度；每个代理登记定义与效度假设。

### B3：真实历史 walk-forward 回测

- 用 B1 真实奖池/中奖注数回放，报告相对随机选号的 EV 增量 + 区间 + 样本量；样本仅 200 期，结论须带不确定性。

### B4：服务治理

- challenger/shadow 治理，不直接晋升 serving，不做收益/中奖保证。

## 5. 决策门与硬边界

- B0 通过后，再决定是否授权 B1（涉及网络采集 + 契约级外部数据）。
- 硬边界：不修改冻结 `bonus.py` 固定奖级表/契约指纹；不重新引入大乐透"新/旧规则"；不虚构官方来源；不做收益/lift/中奖保证；EV 模型必须显式声明假设。

## 6. 风险

- 号码级热度不可观测 → B 的"选号"杠杆效度存疑。
- parimutuel 精确公式版本相关 → 模型用参数化抽象 + 假设声明，待官方规则来源后校准。
- 样本仅 200 期 → 回测 EV 增量的统计功效有限。
- B 不保证达到 2 元；2.3 倍的期望提升需要奖池/热度/择时多重利好叠加。
