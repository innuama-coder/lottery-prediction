# Remote execution constraints

- Execute in the VPS Docker task worktree as the non-root provider user.
- Public network access is allowed only for the read-only reconnaissance step.
- Formal computation, replay, prediction, champion promotion, betting and
  yield claims are out of scope and prohibited.
- The `i01` remote task and its evidence are historical and read-only. This
  iteration must use `i02` and must not reuse an output directory.
- A HOLD is the correct terminal while PIT evidence remains incomplete. It is
  not an acceptance failure and must not be relabeled as success.
