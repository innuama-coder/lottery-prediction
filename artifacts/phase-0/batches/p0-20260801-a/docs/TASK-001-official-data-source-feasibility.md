## 3. P0-02：官方来源实证

### 3.1 大乐透

权威主源为国家体育总局体育彩票管理中心的[大乐透官方开奖入口](https://m.lottery.gov.cn/mkjdlt/)。本执行环境在 2026-08-01 对国家入口、竞彩网历史页及候选历史接口的公开 GET 均收到 HTTP 567；没有重定向，也没有尝试伪造身份或绕过限制。

可公开访问的官方省级渠道为[广东省体育彩票中心逐期开奖公告](https://www.gdlottery.cn/f_html/kjgg/P085_26070.html)。抽查响应为 HTTP 200、UTF-8 静态 HTML，不需要登录、Cookie、验证码或 JavaScript。页面包含期号、开奖日期、全国销售额、出球顺序、排序后的开奖号码、奖级、中奖注数、奖金、奖池和兑奖截止日。

广东渠道属于官方渠道，但接受国家体彩业务体系指导，不能把它与国家主源的相同号码表述为“独立双源真值”；本项目将其标记为 `shared_upstream`。

### 3.2 双色球

权威主源为中国福利彩票发行管理中心的[双色球历史开奖入口](https://www.cwl.gov.cn/ygkj/wqkjgg/ssq/)。本执行环境对历史页、逐期页和候选分页接口的公开 GET 收到 HTTP 403；没有绕过。

可公开访问的官方省级渠道为[广东省福利彩票发行中心双色球历史页](https://www.gdfc.org.cn/sjfx/ssq_200.html)。抽查响应为 HTTP 200、GBK、服务端 HTML；页面最多提供最近 200 期核心号码。该页不提供完整开奖时间，也不能单独覆盖冻结目标区间。广东逐期文章明确标注“来源：中国福彩”，同样属于 `shared_upstream`。

### 3.3 来源门结论

- `G-AUTHORITY`：当前证据支持通过。两个彩种均识别出法定发行机构的国家主源、至少一个官方省级渠道，并明确了共享上游关系；未使用第三方数据作为真值。
- `G-COMPLIANCE`：就已经执行的低频公开探针而言支持通过，因为没有绕过控制，条款、robots、版权和未决问题均已记录。这个工程结论不等于法律批准，也不授权对 403/567 进行规避。
- 可采集能力仍有限：国家主源对本环境不可用，省级渠道的历史深度尚未证明满足目标区间。因此，P0-02 通过不等于 P0-05 覆盖通过。

## 4. P0-03：规则与字段设计

### 4.1 正交规则轴

每一期同时映射四个独立维度：

1. `number_space_version`：号码分区、范围和选取个数。
2. `draw_process_version`：官方规则公开的封存、公证、摇奖及分区先后；不把设备身份或未公告变化猜成新版本。
3. `prize_rule_version`：基础奖级和计奖规则。
4. `active_promotion_ids`：可同时存在多个全国派奖覆盖；不把省级赠票、扫码抽奖等营销活动混入全国计奖规则。

大乐透在冻结区间始终为前区 1—35 选 5、后区 1—12 选 2；第 26014 期从九奖级切换到七奖级。双色球始终为红球 1—33 选 6、蓝球 1—16 选 1；第 2026014 期启用新计奖规则。

规则边界的主要官方证据包括：[大乐透财政部审批](https://www.mof.gov.cn/gp/xxgkml/zhs/202601/t20260116_3982042.htm)、[26013期](https://www.gdlottery.cn/f_html/kjgg/P085_26013.html)、[26014期](https://www.gdlottery.cn/f_html/kjgg/P085_26014.html)、[双色球财政部审批](https://www.mof.gov.cn/gp/xxgkml/zhs/202601/t20260116_3982040.htm)和[双色球新规则 PDF](https://www.gdfc.org.cn/resource/2026/2026011601.pdf)。

### 4.2 派奖覆盖

- 大乐透 2024：高奖级派奖 `24030—24049`；固定奖派奖 `24030—24062`，两者重叠但结束期不同。
- 大乐透 2025：全国派奖 `25038—25057`；25057 仍有派奖字段，25058 已无。
- 大乐透 2026：冻结区间内从 26050 开始固定奖派奖。
- 双色球 2024：一等奖特别派奖 `2024126—2024145`；六等奖翻番 `2024126—2024144`。
- 双色球 2026：从 2026014 起进入“福运奖”特别规定；它是带滞回的状态机，开启门槛和停止门槛不同，不能每期用同一阈值重算。冻结末期 2026050 仍处于开启状态。

当前 `rule-bundles.json` 为两个彩种各生成 350 条唯一映射。2025 年双色球没有发现全国派奖公告；这只表示“审计到的官方目录中未观察到”，不是对不存在的绝对证明。P0-05 将用逐期奖项字段继续核对，若发现相反证据必须追加修订，不得覆盖旧证据。

### 4.3 时间与号码语义

- 排序后的官方开奖号码与物理出球顺序是两个不同事实。阶段 0 的核心号码只采用排序后的官方开奖号码；物理顺序不能混入。
- `page_published_at` 只接受页面明确的发布时间；HTTP `Date`、`Last-Modified`、URL 日期和本系统抓取时间都不能替代。
- `first_seen_at`、`retrieved_at` 和 `available_at` 是系统事实，不能倒推开奖或发布时间。
- 冻结的 normalized-record Schema 把 `draw_at` 设为必填，但当前多数官方历史页面只给开奖日期，不能证明逐期实际摇奖时分秒。字段合同已明确：在取得精确官方证据或完成显式合同修订前，这类记录不得伪造时间并标记为 `verified`。这是 P0-04 必须解决的执行约束。

## 5. P0-04 的最小验收范围

P0-04 不追求一次性抓完整历史。它只需实证以下闭环：

1. 用公开低频 GET 保存准确的响应字节、请求 URL、跳转链、白名单响应头、抓取时间和 SHA-256。
2. 同一原始字节、同一解析器哈希和同一环境锁产生相同规范记录哈希。
3. 号码数量、范围、重复、排序、期号和编码均严格校验。
4. 畸形 HTML、缺字段、越界、重复号、编码损坏、空正文和未验证 OCR 一律失败闭合，不产生 `verified` 记录。
5. 国家主源不可达时，如实记录 `unavailable`；不能由省级核对源静默替代主源角色。
6. 至少用一个大乐透和一个双色球官方响应做端到端重放，再决定是否进入冻结历史区间。

## 6. 当前不能下的结论

- 不能说完整目标区间已经覆盖。
- 不能说国家主源已具备稳定自动访问能力。
- 不能把共享上游说成独立核验。
- 不能把计划开奖时刻当作逐期实际开奖时刻。
- 不能宣布阶段 0、阶段 1或任何预测模型已经通过。
- 数据可行性通过后，也不能由历史开奖数据推出“中奖概率可无限逼近 100%”；公平独立开奖下，历史模式不会消除组合空间的不确定性。
