# Phase4E24 B0：版本化 parimutuel 奖金与 EV 模型

## 模型口径

本交付新增独立版本 `SSQ_PRIZE_PARIMUTUEL_v1` 与
`DLT_PRIZE_PARIMUTUEL_v1`。两种彩票的一、二等奖按输入奖池和中奖者数分摊，
单注奖金为 `floor(pool / winners)`；其余奖级的命中态和金额全部复用冻结的
`bonus.fixed_bonus`。未中奖为 0。冻结固定规则、固定奖级表及其契约指纹没有修改，
大乐透也没有“新/旧规则”分支。

parimutuel 分摊是带假设的模型抽象，并非对官方精确规则的断言。它不覆盖费用、
调节基金、封顶、滚存、追加投注、税费或逐期结算细节。

## EV 公式

对奖级 `i`，`p_i` 来自冻结全空间 oracle：

```text
p_i = tier_winning_counts[i] / total_ticket_count
```

低奖级固定期望逐命中态计算。前区与后区独立，每区使用超几何概率：

```text
P(h hits) = C(k,h) C(n-k,k-h) / C(n,k)
low_ev = Σ_low_states P(front_state) P(back_state) fixed_prize(state)
```

一、二等奖的条件 EV 为：

```text
ev_i = p_i pool_i / ((total_bets - 1) p_i popularity_weight + 1)
total_ev = low_ev + ev1 + ev2
```

`popularity_weight=1` 表示相对均匀，低于 1 表示模型假设本注更冷门、其他同奖级
中奖者更少，高于 1 表示更热门。该权重是情景参数，不是从历史数据估计出的事实。

## 离线探针结论

探针固定假设为总投注 `100,000,000` 注、二等奖池 `100,000,000` 元，目标仅是求解
模型中的 `total_ev >= 2` 边界。结果如下（一等奖池均为满足边界的向上取整整数元）：

| 彩种 | 低奖级固定 EV（元） | w=0.5 | w=1.0 | w=2.0 |
| --- | ---: | ---: | ---: | ---: |
| SSQ | 0.4863104342 | 0 | 61,846,619 | 221,340,859 |
| DLT | 0.5549596205 | 0 | 55,326,372 | 209,846,102 |

`w=0.5` 的一等奖池阈值为 0，是因为在这组强假设下，1 亿元二等奖池加低奖级
固定 EV 已将模型总 EV 推过 2 元；它并不表示现实投注能达到该结果。均匀权重下，
模型需要约 0.55–0.62 亿元一等奖池；热门权重 `w=2` 下则需要约
2.10–2.21 亿元。仓库冻结数据没有逐期奖池、销量或号码热度数据，因此无法据此
判断这些奖池和热度偏离是否现实。探针回答的是条件数学阈值，不是收益、lift、
中奖保证，也不是“实际可以达到 2 元”的声明。

机器可读结果位于 `artifacts/phase4e24_b_parimutuel/ev-probe.json`，可通过
`PYTHONPATH=src python3 scripts/phase4e24_b_parimutuel/run_ev_probe.py` 离线重建。

## 局限

- 所有投注被压缩为总注数与一个相对热度权重，没有建模号码间相关性或真实投注分布。
- 奖池是外生输入，模型不推断销量、滚存或官方分配过程。
- EV 是条件期望而非实现收益；极低概率和多人分摊会产生很高方差。
- 探针不使用外部数据，不能验证输入场景的现实频率或可操作性。
